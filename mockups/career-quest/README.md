# Career Quest — интерактивный мокап

Статический прототип на HTML, CSS и JavaScript. Сборка и установка зависимостей не нужны.

## Запуск

Из корня репозитория (нужен Python 3):

```sh
python -m http.server 8765 --bind 127.0.0.1 --directory mockups/career-quest
```

Откройте <http://127.0.0.1:8765/>. Не открывайте `index.html` через `file://`: данные загружаются через `fetch` и требуют HTTP-сервера.

## Кабинеты

- **HR:** общая аналитика всех 200 сотрудников, фильтры, очередь помощи и подробные карточки с выжимкой GitHub/Jira.
- **Сотрудник:** личный рейтинг развития, матрица требований к целевому грейду, пройденное и предстоящее обучение, собственные демонстрационные подключения.
- **Руководитель отдела:** та же аналитика и карточки, ограниченные в интерфейсе отделом выбранного руководителя. Отдел и руководители определяются по исходному датасету.

Кабинет и демонстрационный профиль переключаются слева. В карточке сотрудника показаны причины приоритета помощи, рабочие эпизоды, предполагаемые зоны роста и рекомендации.

## Данные и ограничения

- `data/` содержит четыре исходных файла синтетического датасета Career Quest: 200 сотрудников, 60 навыков, 32 ролевых профиля, 40 мероприятий и 2743 записи истории.
- Срез расчётов — **01.10.2026**; история — **01.10.2024–30.09.2026**.
- `mock-integrations.js` содержит вымышленные примеры GitHub/Jira. Реальные API и ИИ не вызываются; выжимки формируются по демонстрационным шаблонам.
- Подключения, отметки HR и обновление данных имитируются в памяти страницы и сбрасываются при перезагрузке. Токены и пароли не используются.
- Разделение ролей — **демонстрация интерфейса, не защита доступа**. Все синтетические данные доступны браузеру. Перед использованием реальных данных нужны серверная авторизация, проверка прав на каждом запросе и безопасное хранение интеграционных токенов.
- Личный рейтинг — округлённая готовность по матрице навыков к выбранной цели, а не место среди коллег. Приоритет помощи — прозрачное правило прототипа, не кадровое решение. Отсутствие активности в GitHub/Jira не считается отсутствием навыка.

## Файлы

- `index.html`, `styles.css`, `overrides.css`, `dashboard.css`, `roles.css` — интерфейс.
- `app.js` — загрузка датасета, расчёт навыков, разрывов и рекомендаций.
- `dashboard.js` — демонстрационные подключения и анализ рабочих эпизодов.
- `roles.js` — кабинеты, область отображения, очередь помощи и обучение.
- `mock-integrations.js` — моковые рабочие эпизоды.
